ააწყვე: ოთხი პროექტი

დაიწყე მარტივით, მერე გადადი რთულზე.

დონე: დამწყებიდრო: 10 წუთიასაკი: 7+
  1. აიღე A4 ფურცელი და გაკეცე სიგრძეზე შუაზე, მერე გაშალე.
  2. ზედა ორი კუთხე კეცისკენ მოკეცე, რომ სამკუთხედი გამოვიდეს.
  3. ახალი ზედა კუთხეები კვლავ ცენტრალური კეცისკენ მოკეცე.
  4. მთელი ფიგურა შუაზე გაკეცე და ფრთების ხაზი ორივე მხარეს ჩამოკეცე.
  5. ფრთების ბოლოებს ოდნავ ზევით მოუკეცე. ეს ამარტივებს სტაბილურობას.
  6. გაუშვი ოდნავ ზევით და სუფთად, ნუ ისვრი ძალით.

რჩევა: თუ ცხვირს ეშვება, ფრთების უკანა ნაპირი ოდნავ ზევით მოუკეცე.

დონე: საშუალოდრო: 2 საათიასაკი: 10+
  1. ქაფის ფირფიტაზე (3-5 მმ) დახაზე ფრთა: სიგრძე 60 სმ, სიგანე 12 სმ.
  2. დაჭერი სკალპელით ან პრეციზიულ დანით, ზრდასრულის მეთვალყურეობით.
  3. ფიუზელაჟად აიღე ხის ჩხირი ან 8 მმ პლასტმასის მილი, სიგრძე 45 სმ.
  4. ფრთა დააკრავი ფიუზელაჟის წინა მესამედზე სკოჩით და ცხელი წებოთი.
  5. კუდის ორი მცირე ფირფიტა (15×5 სმ) ფიუზელაჟის ბოლოზე დააკრავი.
  6. ცხვირში ჩადე მონეტა ან ლითონის ბურთულა ბალანსისთვის. ტესტით მოარგე: ფრთის წინა მესამედზე უნდა ეყრდნობოდეს თითზე.
დონე: საშუალოდრო: 1 დღეასაკი: 12+
  1. ბალსის ფირფიტიდან გამოჭერი ფრთის რიბები (ხვრელებიანი ჩონჩხი), 12 ცალი.
  2. რიბები ჩააყენე ორ ლილვზე (ლონჟერონი) და ჩამოაკრავი ცელულოზის ან ხის წებოთი.
  3. ფრთა დახურე თხელი შეფუთვის ქაღალდით და წყლის სპრეით გააჭიმე.
  4. ფიუზელაჟი: ბალსის 4 ბრტყელი ზოლი ან კარბონის ღერო.
  5. კუდი: ორი ბრტყელი მართკუთხედი და ვერტიკალური სარკმელი.
  6. გაუშვი ბალახიან ადგილას. გაასწორე ბალანსი პლასტილინით ცხვირში.
დონე: მოწინავედრო: 1-2 კვირაასაკი: 14+
  1. აიღე ფოამბორდის (Dollar-tree foam) ფიუზელაჟი და ფრთა, სიგრძე 80-100 სმ.
  2. ცხვირში განათავსე უჯრედიანი ძრავა (Brushless 2212) და 8x4 პროპელერი.
  3. დაუკავშირე ESC (ძრავის კონტროლერი) და 3S LiPo ბატარეა.
  4. ორი სერვო მოარგე ელერონებს, ორი — ლიფტსა და სარკმელს.
  5. დააკავშირე მიმღები (Receiver) და გამოსცადე პულტი მიწაზე.
  6. ბალანსი: მძიმე ელემენტები (ბატარეა) ისე გადაანაცვლე, რომ ცენტრი ფრთის წინა მესამედზე იყოს.
  7. პირველი ფრენა დაიწყე მოედანზე, ნელი სვლით და ზრდასრულის დახმარებით.

ფრენის კონტროლერი

პატარა დაფა (მაგ. Arduino ან Matek), რომელიც სენსორებს კითხულობს და სერვოებს უბრძანებს.

GPS

ავტომატური დაბრუნება სახლში, თუ სიგნალი გაქრა. ზოგ მოდელს აქვს.

პირველი რობოტული პროექტი: ავტომატური ფრთის სტაბილიზაცია

Arduino და MPU6050 სენსორი ფრთის დახრას ზომავს და სერვოს ისე ატრიალებს, რომ ფრთა პირდაპირ დარჩეს. ეს არის კონტროლის ციკლი: გაზომე → შეადარე → გამოასწორე.

#include <Wire.h>
#include <Servo.h>
#include <MPU6050.h>

MPU6050 imu;
Servo aileron;

void setup() {
  Wire.begin();
  imu.initialize();
  aileron.attach(9);
}

void loop() {
  int16_t ax, ay, az;
  imu.getAcceleration(&ax, &ay, &az);
  float roll = atan2(ay, az) * 57.3;   // დახრა გრადუსებში
  int servoAngle = 90 - roll * 1.5;      // 1.5 = გამაძლიერებელი
  aileron.write(constrain(servoAngle, 45, 135));
  delay(10);
}

ეს ძირითადად საჩვენებელია. ნამდვილი ფრენის კონტროლერი იყენებს PID რეგულატორს, ანუ უფრო ჭკვიან ფორმულას, რომელიც მეტ-ნაკლებ გასწორებას ასწორებს.

საინტერესო ფაქტები

1903ძმებმა რაიტებმა პირველი ძრავიანი თვითმფრინავი 12 წამს გაფრინეს. მანძილი 36 მეტრი იყო.
რეკორდიქაღალდის თვითმფრინავმა 2012 წელს ჰაერში 27,6 წამი დაჰყო. ყველაფერი ფორმასა და გაშვების ტექნიკაზეა.
ბუნებაფრთის პროფილი ჩიტების ფრთიდან ისწავლეს. ფრენის ბევრი იდეა ბუნებიდანაა აღებული.
მარსიNASA-ს მცირე ვერტმფრენი Ingenuity მარსზე დაფრინავდა, სადაც ჰაერი დედამიწაზე 100-ჯერ თხელია.
დრონებითანამედროვე დრონი წამში ასეულობით ჯერ ცვლის ძრავების სიჩქარეს, რომ ჰაერში გაჩერდეს.
ბალანსიხშირად მოდელს ცხვირი ეშვება, რადგან მისი ცენტრი ძალიან წინაა. 5 გრამიც კი ცვლის ყველაფერს.

უსაფრთხოება

  • ბასრ იარაღთან (სკალპელი) იმუშავე მხოლოდ ზრდასრულის თანდასწრებით.
  • LiPo ბატარეა დატენე თვალის გარეშე არასოდეს და ცეცხლგამძლე ადგილას.
  • პროპელერი ბრუნვისას საშიშია. ძრავა ჩართე მხოლოდ მაშინ, როცა ხელები შორსაა.
  • იფრინე ღია მოედანზე, ხალხისგან, ხეებისა და ელექტროგადამცემი ხაზებისგან მოშორებით.
  • ადგილობრივი წესები: დრონებისა და რადიომოდელების ფრენა შეიძლება კანონით შეზღუდული იყოს.
